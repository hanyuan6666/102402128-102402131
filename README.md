# 校园失物招领 🏠

一个纯前端（HTML + CSS + JavaScript）实现的校园失物招领 Web 应用，数据存储在浏览器 localStorage 中，无需后端、无需安装依赖，用 Chrome 浏览器直接打开即可运行。

---

## 功能概览

- **浏览信息**：首页以卡片列表展示全部失物招领 / 寻物启事，按日期倒序排列
- **搜索**：按物品名称、描述、地点关键词实时搜索
- **类型筛选**：全部 / 寻物启事 / 失物招领 三个 Tab 切换
- **类别筛选**：按证件、电子产品、钥匙、书籍、生活用品等类别筛选
- **查看详情**：点击卡片进入详情页，查看物品描述、地点、发布人、联系方式
- **一键复制联系方式**：详情页一键复制 QQ/微信/电话，方便联系
- **发布信息**：填写表单发布寻物或招领信息
- **更新状态**：发布者可将信息标记为「已找到 / 已归还」，也可重新打开
- **我的发布**：集中管理自己发布的信息，支持标记解决、重新打开、删除
- **空状态提示**：无搜索结果、无发布记录时均有友好提示

## 目录结构

```
campus-lost-found/
├── index.html        # 首页：物品列表 + 搜索 + Tab筛选 + 分类筛选
├── detail.html       # 详情页：物品详细信息 + 联系方式 + 状态更新
├── publish.html      # 发布页：填写寻物/招领信息表单
├── my.html           # 我的发布：管理自己发布的信息
├── tests.html        # 单元测试页面（直接在浏览器打开即可运行）
├── css/
│   └── style.css     # 全部样式（移动端优先，适配桌面浏览器）
├── js/
│   ├── data.js       # 数据层：localStorage CRUD + 搜索 + 筛选（核心业务逻辑）
│   └── app.js        # 视图层：各页面渲染与交互逻辑
└── README.md         # 本文件
```

---

## 如何运行

1. 确保已安装 **Google Chrome** 浏览器
2. 下载本项目所有文件到本地同一目录
3. 用 Chrome 打开 `index.html` 即可使用全部功能

> 不需要启动服务器、不需要安装 npm 包、不需要联网。所有数据保存在浏览器本地。

### 运行单元测试

用 Chrome 直接打开 `tests.html`，页面会自动执行 12 个测试用例并显示通过/失败结果。

## 技术说明

- **前端**：原生 HTML5 + CSS3 + 原生 JavaScript（ES5 语法，无框架依赖）
- **数据存储**：`localStorage`，键名 `campus_lost_found_items`
- **响应式**：移动端优先设计，最大宽度 480px 居中，桌面浏览器下同样美观
- **XSS 防护**：所有用户输入在渲染时经过 `escapeHtml()` 转义

## 核心流程

```
发布信息 → 浏览/搜索列表 → 查看详情 → 复制联系方式联系发布者 → 发布者标记"已找到/已归还"
```
